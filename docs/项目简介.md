## 3. 自我介绍（30 秒，口头）

> 我做过一个 A 股因子研究项目。最开始回测年化 12%、夏普 0.75，看起来不错。但我把它放到全市场股票池、加上真实成本之后，收益就没了。进一步做 IC 和分层检验，发现 A 股的动量因子是反向的——买涨得多的反而亏。最后找到一个真正有效的流动性因子，但算下来只能容纳两千万资金。整个过程我写成了研究日志开源在 GitHub 上。

## 4. 面试问答

**问：你最大的收获是什么？**

> 我学会了一个判断标准：回测跑赢指数不算数，要和「全池等权」比。因为只要等权持有全市场就能有 11%，跑不赢它的策略等于没有 alpha。这个标准帮我省了很多时间。

**问：怎么保证回测没有未来函数？**

> 信号和成交分离：月末收盘算因子，次一交易日开盘才成交；换仓日收益从开盘算到收盘；所有滚动窗口都是向后看的；参数只在样本内定，样本外不调。

**问：遇到过什么问题？**

> 两次。一次是上市满 250 天的过滤写成了全局滚动窗口，把 2019 年整年筛空了，收益显示 0%——回测里某年收益恰好为 0 几乎总是 bug。另一次是前复权数据把 6 只高分红股算成了负价格，制造出几百个百分点的假收益。

## 6. 写作提醒

- **不要写收益率当卖点**。「年化 12%」会被追问样本外和成本，而你自己的结论是它无效。写「验证并证伪」反而是加分项。
- **关键词**：因子检验、IC/IR、分层回测、幸存者偏差、交易成本建模、容量分析。这些是行内人一眼能认出的东西。
- **放「项目经历」栏，不要放「实习经历」**。大一没有实习很正常，项目栏有这样一个，已经比多数同届强。
- 被问到不会的，直接说不会。这个项目里你已经踩过真实的坑，比背概念可信得多。
